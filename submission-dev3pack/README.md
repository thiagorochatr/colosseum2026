# Alibi · submission

Alibi is a compliance layer for private payments. A withdrawal proves in zero knowledge that it comes from a deposit in the clean set, without revealing which one. On Solana it wraps an existing privacy pool, mirror-pool, unchanged; on Tempo the clean set is the stablecoin issuer's own TIP-403 policy. One circuit and one verifying key serve both chains.
